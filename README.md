# Deviceplugindemo
为自定义硬件接入k8s所需要实现的简单demo示例


## Getting started
下载项目代码到本地 使用 go build . 方式生成可执行文件在k8s/k3s集群内主机上运行。目前裸机上运行，根据项目实际需求，可变动到云上部署，建议采用daemonset的方式进行部署。
